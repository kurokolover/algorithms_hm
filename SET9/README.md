# задача A1
## Эмпирические замеры производительности алгоритмов сортировки строк

### Файлы:
  results.csv   - результаты замеров (540 строк)
  
  benchmark.cpp — исходный код бенчмарка

### Формат results.csv:
  dataset      — тип массива: random / reverse / nearly
  
  algorithm    — алгоритм: QuickSort, MergeSort, StringQuickSort, StringMergeSort, MSDRadix, MSDRadixQuick
  
  n — размер массива (100..3000, шаг 100)
  
  time_us      — среднее время работы, микросекунды (7 запусков)
  
  char_comps   — среднее число посимвольных сравнений (7 запусков)

### Условия:
  Алфавит:     74 символа (A-Z, a-z, 0-9, !@#%:;^&*()-.)
  
  Длина строк: 10..200 символов (равномерное распределение)
  
  Seed:        42 (воспроизводимая генерация)
  
  Повторений:  7 (берётся среднее)
